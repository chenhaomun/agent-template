# Maintenance skill-pack (deferred)

One-off/meta skills kept out of the always-loaded skill listing to save context.
Loaded on demand, not surfaced as a standing `/`- or `$`-command.

- `caveman-compress` — compress a memory/instruction file in place (local deterministic script).
- `skill-maintenance` — refresh/review project-local agent skills.

Pin every skill here in `skills-lock.json` with a matching `localPath` (enforced by
`.agents/tools/check_template.py`). Run `make sync` and `make check-template` after edits.
